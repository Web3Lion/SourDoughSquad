# SourDoughSquad
Superhero sourdough bakery site.

- `index.html`: storefront with cart and checkout
- `dashboard.html`: owner dashboard (bake list, progress, order board)
- `js/config.js`: order log URL, payment settings, menu
- `google-apps-script/Code.gs`: Google Sheets order log

See [SETUP.md](SETUP.md) to connect the order log and PayPal/Square.
